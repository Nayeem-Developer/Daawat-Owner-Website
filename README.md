# Daawat Owner

This repository now contains two owner surfaces:

- `owner-mobile-app/`: the new React Native CLI owner app.
- Root Vite app: the older website/dashboard, kept temporarily as a reference while the mobile app is adopted.

The website flow should be treated as deprecated for future owner-facing work. New owner features should be added to the mobile app unless there is a specific reason to keep them on the web dashboard.
